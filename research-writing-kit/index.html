研究寫作套件

一套用 AI 協助寫研究論文與計畫提案的方法，加一個會自己安裝、自己客製的小工具箱。你不用懂 AI、不用會設定：把資料夾交給你的 Claude，它會問你幾個問題，再把適合你的工具建好。

到 GitHub 取得 research-writing-kit

這是什麼

不是模板，是方法

它不是那種「寫好給你貼上去」的東西。你擁有想法與論證，AI 負責跑腿——找文獻、查證引用、架論證骨架、寫成稿、再自己檢查。五個原則貫穿整套流程：

  1. 先架骨架再寫字不從空白頁硬擠出稿——那種硬擠就是「AI 味」的來源。先把論證結構立好，再照著它寫成文字。
  2. 絕不編造引用每一條文獻都真的抓下來、確認方向對；查不到就標「未驗證」，不假裝。交付前還會掃撤稿與沒掛引用的宣稱。
  3. 像你的聲音用母語寫時對齊你自己的文風，不磨成通用 AI 腔；英文稿交付前另有去節奏的複查。
  4. 誠實內建效果量與信賴區間（不只 p 值）、Likert 不當連續變數、要主張效果先診斷設計能不能回答問題。
  5. 資料留在你電腦未發表稿件與研究原始資料永遠不上傳；線上服務只拿到 DOI 與標題這類書目資料。

怎麼開始

三步，五分鐘

  1. 拿到資料夾。公開 repo，不用登入；有 git 就 clone，沒有就在 GitHub 頁面按 Code → Download ZIP。 
    git clone https://github.com/chenweichiang/research-writing-kit.git
  2. 在資料夾裡打開 Claude Code（需付費的 Claude 方案；免費的 claude.ai 帳號不能用）。 
    cd research-writing-kit
claude
  3. 貼這一句話，剩下的交給它：它會問你寫什麼、用什麼語言、想投哪、有沒有舊稿可以學你的文風，然後生成專屬於你的 skill。 「讀 CLAUDE.md，幫我設定。」

還在 claude.ai 網頁版、沒有 Claude Code？把 repo 連給網頁版的 Claude 說同一句話，它會一步步帶你裝好再搬過去（setup/WEB.md）。

之後每天怎麼用

用講的就好

在放論文的資料夾裡開 Claude Code，像平常講話一樣說要做什麼；也可以直接打 /skill名。

「幫我寫這篇論文／提案」/co-author
協作寫作：找文獻、架骨架、寫成稿、交付前六道關卡（撤稿、無引用宣稱、數字帳本、圖表溯源、投稿聲明、終審）。
「幫我檢查這篇再投」/paper-review
五層檢查：機械層、用字、語言、審稿視角的邏輯、交付完整性；只檢查不改稿。
「這些引用撐得住我寫的話嗎？」/verify-citations
逐句對照 PDF 原文判定引用方向，DOI 權威查驗，被標記的再派懷疑論二審。
「幫我把引用的 PDF 收齊」/fetch-refs
多源抓取、逐篇確認內容真的相符、歸檔；含引用滾雪球。
「審稿意見回來了，幫我回」/rebuttal
拆點、逐點裁定、落實修訂、回應信、交付前完整性驗證。
「別再犯同樣的錯」/doc-regress
把抓到的錯寫成常駐檢查，改完全庫重掃，復發就擋下；數字帳本勾稽。
「把這篇排成投稿 PDF」/build-pdf
依場域模板排版；第二語言稿連同回譯稿成對交付。

裡面有什麼

方法、範本、十五支工具

  • 方法本體四份：心法、鐵則、八個 Phase 的流程、論證工法。
  • 七個 skill 範本與兩個 subagent：安裝時依你的領域、語言、場域改寫，不是原檔複製。
  • 十五支本機腳本，多數零安裝：台灣用語與中文 AI 味檢查、英文文法與 AI 指紋、圖表色覺可及性、撤稿掃描、無引用宣稱掃描、文件回歸、回應信與投稿狀態驗證。
  • 空白模板（文風檔、投稿筆記、論證骨架）、三份開放學術詞表、一份填好的骨架範例。
  • 繁中在地化包：陸用語對照、台／臺一致性、Typst 中文 PDF 配方。

全部細節在 repo 的 README.md：安裝後電腦會多出什麼、論文專案裡會長出哪些檔案、外部程式與線上服務各自被誰用到。
